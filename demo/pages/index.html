cursed-sqlite-turbo

Turbo makes SQLite's complex read queries faster without changing SQL, the planner or the file format. It takes the bytecode SQLite has already compiled for a statement and, when it can produce exactly the same rows more cheaply, runs its own executor instead. Otherwise it hands the statement back to SQLite's interpreter, unchanged.

Experimental: every result is checked against stock SQLite, but nobody runs this in production yet. Pinned to SQLite 3.54.1. MIT licensed.
